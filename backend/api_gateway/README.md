# api_gateway

## 名称
对外 API / BFF：鉴权、请求聚合、统一错误码；frontend 唯一入口。

## 生产数据与落库表

| 生产数据 | 落库表 | 写入时机/说明 |
| --- | --- | --- |
| 无业务主数据 | — | 只读查询或转发命令；业务写入由领域模块落库 |
| （可选）审计日志 | `api_audit_log`（待建） | 若启用网关审计再落库 |


## 本目录模块一览
无子模块；本目录即单一模块实现。

## 协作模块索引（供 AI Agent）

| 模块 | README | 主要作用 | 与本模块关系 |
| --- | --- | --- | --- |
| backend（父） | `../README.md` | 总览 | 父目录 |
| frontend | `../../frontend/README.md` | UI | 下游调用方 |
| orchestrator | `../orchestrator/README.md` | 任务触发 | 转发「启动任务」类请求（传 ID/参数） |
| 各业务模块 | `../README.md` | 领域能力 | 只读查询/写操作经本层转发，不直暴露内部 |

## 边界
- 做：HTTP/WS 入口、鉴权、DTO 校验、聚合只读查询、把命令转为对 orchestrator/领域任务的引用调用。
- 不做：因子计算、撮合、过账；直连让 frontend 拿到 DB 连接；代替 risk_engine 做放行。

## 输入
- 前端/外部客户端请求
- 库中已落库的可查询状态（经各领域读模型）

## 输出
- 统一 API 响应
- 触发任务时只传引用与标量参数

## 运行
- 待定：独立网关进程

## 不变量
- frontend 不得绕过本模块访问其他 backend 内部口（约定）
- 不返回未授权账户数据
